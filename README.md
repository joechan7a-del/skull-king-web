# 骷髏王（網頁版）

用電話瀏覽器就可以同朋友一齊玩 Skull King。一部電話開房攞到一個短房號（或者分享 `/r/AB3K` 連結），另一部輸入同一個號就入到去，之後一齊叫牌、出牌。唔使 Apple 帳號，亦唔使上 App Store。

用現行 **Grand Prix 規則**（2021 年起），包括八爪魚同白鯨，計分同贏牌規則跟官方。牌組係 74 張家規套：官方 72 張再加多一張黑 14 同多一張母老虎。共 5 局（第 1 局各 6 張，去到第 5 局各 10 張）。呢個版本**暫時唔包括**贓物牌。

2 至 6 人。房主可以揀人數，並用電腦對手補滿空位（預設 4 人桌，用電腦補位；兩個人加入就係 2 人 + 2 個電腦）。電腦花名每場從海賊名池隨機抽，同一場五局內唔會換；頭像顏色跟座位，整場都唔會轉。

## 本機運行

需要 [Node.js](https://nodejs.org/) 18 或更新。

```bash
cd SkullKingWeb
npm install
npm start
```

然後用瀏覽器打開 http://localhost:3000

啟動時終端機會印出區域網絡位址。預設監聽所有網卡、埠口 3000；可以用環境變數改：

```bash
PORT=8080 npm start
```

跑規則同遊戲測試：

```bash
npm test
```

## 同一 Wi-Fi、兩部電話玩

暫時唔使公網伺服器。只要運行 `npm start` 嗰部電腦同兩部電話喺同一個 Wi-Fi：

1. 睇啟動時印出嘅位址，例如 `http://192.168.1.23:3000`（喺電腦用 localhost 打開主頁時，如果偵測到區域網絡 IP，頁面下方都會顯示）。
2. 兩部電話嘅瀏覽器打開呢個位址（iPhone 用 Safari、Android 用 Chrome 都可以）。
3. 一部撳「開房」，把房號或連結傳給對方；另一部撳「加入」。
4. 有需要就開「用電腦補滿空位」，房主撳「開始遊戲」。

如果電話打唔開呢個位址，檢查電腦防火牆有冇放行 3000 埠口，同埋電話係咪連咗訪客 Wi-Fi（有啲路由器會隔離裝置）。

刷新頁面或者收線之後，只要房間仲喺，用返同一部電話打開同一個連結就可以繼續（座位憑證存在瀏覽器 localStorage）。伺服器關機或者好耐冇人玩，房間就會消失。

## 部署到公網（方便隔住互聯網玩）

本專案**冇附帶已開好嘅公開網址**。要讓朋友喺外面嘅網絡都能連線，需要你自己開一個雲端服務，把呢個資料夾放上去。下面以 **Render** 為建議做法，步驟最少；Railway 同 Fly.io 都得。

免費方案有時會休眠，第一下打開可能要等半分鐘。呢個應用只用記憶體保存房間，服務一重啟，進行中嘅牌局就會消失。

### 建議：Render

1. 把本專案放到一個 Git 倉庫（GitHub / GitLab 都可以）。
2. 喺 [Render](https://render.com/) 用電郵註冊，選 **New > Web Service**，接上個倉庫。
3. 設定：
   - **Runtime**：Node
   - **Build Command**：`npm install`
   - **Start Command**：`npm start`
  Render 會自動提供 `PORT`，程式會跟呢個變數來聽。
4. 建立服務之後，會得到一個 `https://xxxxx.onrender.com` 網址。兩部電話打開呢個網址就可以開房連線。

### 其他選擇

**Railway：** 註冊 [Railway](https://railway.app/)，New Project > 部署 GitHub 倉庫或用 Railway CLI 喺呢個資料夾執行 `railway up`。Start command 用 `npm start`。

**Fly.io：** 安裝 [flyctl](https://fly.io/docs/flyctl/install/)，喺呢個資料夾執行：

```bash
fly launch --name 你想用嘅名 --no-deploy
fly deploy
```

資料夾入面已經有 `Dockerfile` 同 `fly.toml` 範本，埠口用 `PORT`（預設 3000）。

無論邊個平台，都要開 **WebSocket**（路徑 `/ws`）。以上幾個都預設支援，唔使額外設定。用 HTTPS 網址時，瀏覽器會自動改用 `wss://`。

## 玩法摘要

- 共 5 局，第 1 局每人 6 張，之後每局多一張，第 5 局各 10 張；出牌前大家同時預測會贏幾多回合。
- 有花色就要跟花（如果出數字牌）；特殊牌（包括八爪魚同白鯨）隨時可出。黑色骷髏旗係王牌。八爪魚或白鯨先出，呢個回合就冇得跟花。
- 人魚捕獲骷髏王；骷髏王大過海盜；海盜大過人魚同數字牌。母老虎出牌時要宣布當海盜定逃脫。
- 八爪魚會食咗整個回合，無人贏；下一回合由「如果冇出八爪魚會贏嗰個人」先出。白鯨令特殊牌唔可以贏，由最高點數嘅數字牌贏（唔分花色同王牌）；如果淨係特殊牌，呢個回合作廢，由出白鯨嗰個人先出下一回合。同一回合兩張獸牌一齊出現，得第二張有效。
- 估中叫牌先有分同獎勵：普通 14 各 +10，黑 14 +20；海盜捕人魚 +20；骷髏王捕海盜 +30；人魚捕骷髏王 +40。白鯨之下由數字牌贏嘅話，14 獎勵仍計，捕獲獎勵就唔計。
- 如果人魚、海盜同骷髏王同時出現，一定係人魚贏，而且只計 +40，唔計海盜相關獎勵。

## 專案結構

- `server/rules.js`：規則（出牌合法性、贏回合、八爪魚／白鯨、計分），伺服器同測試共用。
- `server/game.js`、`server/rooms.js`、`server/ai.js`、`server/index.js`：遊戲狀態、房間、電腦對手、HTTP + WebSocket 伺服器。
- `public/`：手機優先嘅網頁介面（廣東話）。
- `test/`：規則同遊戲自動化測試。

伺服器係唯一真相來源：發牌、檢查是否跟花、計邊個贏回合同分。客戶端出非法牌會被拒絕。
